# Project Supreme Directive

The project exists to independently recreate every legally observable or measurable Sons of the Forest behavior, rule, state, interaction, feedback loop, timing relationship, edge case, and system characteristic that can be established with evidence.

- Evidence must guide specifications, architecture, implementation, tests, and gap analysis. A generic substitute is not acceptable when relevant behavior is known.
- Production code and assets must be independently designed and created for this repository. Do not copy proprietary source, binaries, extracted assets, line-converted dumps, or unlawfully sourced material.
- Structural dumps, mods, trainers, and the audited old project are research leads only. They never supply code or unverified defaults.
- Every feature report must distinguish recreated behavior, provisional engineering choices, and remaining differences or unknowns.
- Unknown values must remain replaceable and configurable; they must not be invented or presented as facts.
- Compilation and passing tests establish software health, not parity with Sons of the Forest. A feature is complete only when its claimed fidelity is supported by evidence and its remaining gaps are explicit.
