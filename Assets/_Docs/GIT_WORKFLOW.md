# Git Workflow

- Use one feature per branch or commit.
- Do not mix gameplay, editor, and asset-cleanup changes in one commit.
- Always validate the Unity compile state before committing.
- Always stage by allow-list.
- Never stage unrelated imported or demo files.

## Commit message examples

```text
chore: initialize rebuild project foundation
chore: add architecture docs
feat: add player foundation runtime
feat: add interaction contracts
```
