# Independent Forest Geometry

The FBX files in this directory are original project assets generated by
`Tools/ArtPipeline/generate_forest_geometry.py` with Blender 4.5.11 LTS.
No model, mesh, texture, source code, or extracted asset from Sons of the
Forest was used.

The generator is deterministic and creates only closed geometry:

- tapered tube trunks and primary, secondary, and tertiary branches;
- closed triangular-prism conifer needles;
- closed curved and tapered grass blades;
- fern stems and volumetric lanceolate pinnae.

It deliberately creates no foliage cards, billboard planes, alpha-cutout
meshes, cameras, lights, animation, or armatures.

The supplied Sons of the Forest screenshots guide only observable silhouette,
canopy layering, clustering, and scale targets. The supplied `NATURAL_REFERENCE`
pack guides biological plausibility. These assets are an independent design,
not a reconstruction of proprietary source geometry.

The bark material reuses the already tracked Poly Haven Fir Sapling bark maps.
Poly Haven publishes that source under CC0:
https://polyhaven.com/license

The current species profile, needle dimensions, colors, density, and material
response remain provisional and replaceable as stronger evidence is collected.
