# Poly Haven model trial sources

Purpose: small CC0 model trial for improving the forest-camp visual baseline before choosing a permanent art source.

License conclusion: Poly Haven assets are published as CC0. These trial files may be used, modified and redistributed in this project. Source pages should remain documented so future art reviews can trace where each candidate came from.

Downloaded resolution: 1K FBX packages.

Candidates:

- `fir_sapling` — https://polyhaven.com/a/fir_sapling
  - Role: conifer sapling candidate.
  - Initial reason: real scanned/geometry-node conifer structure; much better visual baseline than procedural pole/card trees.
- `pine_sapling_small` — https://polyhaven.com/a/pine_sapling_small
  - Role: young pine candidate.
  - Initial reason: pine branch/needle structure close to the desired survival-forest direction.
- `rock_09` — https://polyhaven.com/a/rock_09
  - Role: forest boulder/loose rock candidate.
  - Initial reason: believable weathered rock silhouette at low import size.
- `rock_moss_set_02` — https://polyhaven.com/a/rock_moss_set_02
  - Role: moss/stone cluster candidate.
  - Initial reason: helps test rock-ground blending and moss coverage rules.
- `stone_fire_pit` — https://polyhaven.com/a/stone_fire_pit
  - Role: campfire stone ring candidate.
  - Initial reason: a realistic stone fire-pit base, to replace the weakest current campfire geometry later if approved.

Rejected for this first trial:

- `pine_tree_01` and `fir_tree_01` looked relevant but were not downloaded in this pass. The 1K FBX/GLTF packages are hundreds of megabytes and the source polycounts are multi-million, so they should be evaluated separately before being committed.
